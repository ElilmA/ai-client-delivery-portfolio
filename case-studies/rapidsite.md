# RapidSite Multilingual Website Product

**Live product:** https://guanwang.cc.cd/  
**Role:** Full-stack product developer  
**Stack:** TypeScript, Vite, Cloudflare Pages, Workers, responsive Web UI

![RapidSite live product](../assets/guanwang-live.png)

## Product

RapidSite is a public website-delivery product for small businesses that need a multilingual, mobile-responsive site without a long custom build. The public experience includes industry templates, pricing and process guidance, a content-submission path, and a multilingual English/Chinese interface.

## What I built

- Designed and implemented the public acquisition site and its responsive layout.
- Built reusable industry-template pages and a content-intake workflow.
- Connected the frontend to Cloudflare-hosted endpoints and production deployment.
- Added localized interface copy, metadata, and clear calls to action.
- Verified the production domain, template routes, form behavior, and static assets after deployment.

## AI-assisted workflow

The implementation and visual iteration used Codex-assisted development: generate bounded UI and content changes, review the resulting layout and interaction behavior, then verify the deployed page rather than treating generated code as finished work.
